How the lab works.

ByteCraftCo is a standards and data lab, with a device measurement programme opening soon. Today we turn manuals, warranties and prices into ratings you can check, scored against a written Standard.

01 Write

Write the Standard.

Five scored lines: Build, Evidence, One job, Value and Company. Published, with a dated changelog, so anyone can see how the method works and how it has changed.

02 Collect

Collect the evidence.

Specs, warranty terms, manuals, prices and owner reviews, each with the date we read it. We read the fine print so you don't have to.

03 Publish

Publish the rating.

On The Modern Recovery, with every source linked so readers can check the work.
